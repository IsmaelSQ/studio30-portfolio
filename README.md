# Studio 30 Portfolio

Static portfolio pages for Studio 30 and Joshua Carty, built with HTML, CSS, and JavaScript.

## Pages

- `index.html` — Studio 30 agency portfolio and campaign carousel.
- `joshuacarty/index.html` — Joshua Carty portfolio and campaign gallery.

## Public URLs

- Studio 30: https://ismaelsq.github.io/studio30-portfolio/
- Joshua Carty: https://ismaelsq.github.io/studio30-portfolio/joshuacarty/

Open either page in a browser, or serve this folder with a local static web server to test the video previews.

## Public demo notes

The Joshua Carty lead form is intentionally disconnected in this public portfolio copy. It demonstrates the form UI and client-side validation but does not send or store visitor data. The Apps Script integration and the visitor PDF are excluded.

Campaign media and third-party brand marks are shown as portfolio samples. Their respective owners retain their rights.
